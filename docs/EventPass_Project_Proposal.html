2. Project Background & Problem Statement

Academic institutions, student organizations, and professional bodies organize frequent seminars, orientations, and technical conferences. Two major operational pain points persistently disrupt these events:

  1. Bottlenecked Attendance Logging: Reliance on manual pen-and-paper sign-up lists produces congested registration counters, proxy attendances, illegible handwriting, and lost records.
  2. Tedious Post-Event Certificate Distribution: Manually editing attendee names onto digital templates and emailing them individually takes days or weeks, creating administrative fatigue and lost certificates.

EventPass resolves both hurdles by introducing pre-event registration with instant unique QR code passes, live web-camera check-ins, and automated vector-quality PDF certificate generation delivered on demand immediately upon verified attendance.

3. Objectives of the Study

General Objective:

To build a responsive, client-side capable web application that streamlines event attendee registration, enforces secure QR verification at entrance gates, and automates instant personalized certificate distribution.

Specific Objectives:

  • Create an intuitive registration portal that issues personalized scannable passes upon submission.
  • Incorporate a responsive camera-based QR code scanner capable of validating attendees in less than one second.
  • Prevent unauthorized entries and proxy sign-ins through single-use verification state tracking.
  • Implement an in-browser PDF certificate engine that embeds customized event credentials, official seals, and verification QR stamps.
  • Equip event directors with an analytics dashboard providing real-time turnout metrics and one-click CSV attendance roster exports.

5. Core Functional Modules

Module Description
1. Registration & Pass Module Gathers attendee metadata, performs client validation, and renders a unique digital QR pass.
2. Live Camera Scanner Module Accesses device cameras via WebRTC to read attendee QR passes with instant audio-visual confirmation.
3. Validation Engine Ensures passes cannot be scanned multiple times and validates token integrity in real time.
4. Dynamic Certificate Engine Generates high-resolution vector PDF certificates with custom typography, date stamps, and attendee names.
5. Analytics & Roster Manager Renders real-time check-in stats, searchable attendee lists, and CSV export capabilities.

6. Technical Specifications

  • Frontend Architecture: HTML5 semantic markup with modern Vanilla CSS styling (Design tokens, Glassmorphism, CSS Grid & Flexbox, responsive breakpoints).
  • Application Logic: Pure Vanilla JavaScript (ES6+ modular classes, LocalStorage persistence, event delegation).
  • QR Engine: Canvas-based generator (`QRCode.js`) & camera scanning stream decoder (`Html5-QRCode`).
  • Certificate Rendering: High-DPI canvas & client-side vector PDF renderer (`jsPDF`).
  • Hosting / Deployment: Zero-backend serverless hosting on Vercel, Netlify, or GitHub Pages.
